# 💼 Smart Job Portal

---

## 📌 About the Project

This is a Full Stack Java web application developed using Spring Boot, Thymeleaf, MySQL, and Bootstrap.

The purpose of this project is to provide a simple job portal where users can register, log in, search for jobs, and apply for available opportunities. It also allows job management through basic CRUD operations.

---

## ✨ Features

* User Registration
* User Login
* Session Management
* Add New Job
* View All Jobs
* Search Jobs by Job Title
* Edit Job Details
* Delete Job
* Apply for Jobs

---

## ▶️ How to Run

1. Clone this repository.
2. Open the project in Eclipse or Spring Tool Suite.
3. Configure the MySQL database in `application.properties`.
4. Run the Spring Boot application.
5. Open your browser and visit:

`http://localhost:8080`
